# AI use disclosure

The initial 0.1.0 design, MoonBit implementation, tests, examples, documentation and delivery automation were produced with an AI coding assistant at the participant's request. AI use does not establish correctness or novelty. The participant remains responsible for reviewing and maintaining the submission and complying with competition rules.

Verification is executable: strict compiler checks, an independent polynomial arithmetic oracle, cross-path rank comparisons, invariant/boundary tests, runnable workflows, actual remote CI and a fresh exact-version consumer. These are bounded evidence, not a formal proof or security audit. No claim of human-written-only code is made.

No third-party implementation was copied. Adjacent projects were inspected for capability comparison; see docs/provenance.md and docs/competition/duplicate-check.md. All test payloads are synthetic; the CRC standard check vector is identified explicitly.
